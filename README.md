# AI Engineering Lab

A hands-on learning and experimentation repository focused on understanding, implementing, and evaluating the core technologies behind modern AI applications.

## Learning Philosophy

**Theory → Intuition → Implementation → Experiment → Evaluation → Documentation**

The goal is to understand the underlying concepts rather than simply use AI frameworks.

## Learning Modules

| Module | Focus |
|---|---|
| 01 — ML Fundamentals | Vectors, matrices, similarity, and core ML mathematics |
| 02 — LLM Fundamentals | Tokenization, embeddings, attention, and transformers |
| 03 — LLM Application Basics | Prompting, structured outputs, APIs, and tool calling |

Additional modules covering vector search, RAG, RAG evaluation, agents, MCP, and fine-tuning will be added as the learning progresses.

## Engineering Principles

- Implement important concepts independently.
- Run experiments and record actual results.
- Document limitations and trade-offs.
- Write clean, understandable Python.
- Connect relevant experiments to Enginuity-AI.
- Prioritize depth and reproducibility over the number of projects.
