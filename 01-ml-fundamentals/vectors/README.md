# Vector Magnitude — Python Implementation

## 1. Objective

Understand how vectors represent numerical information and implement vector magnitude calculation using Python.

## 2. What Is a Vector?

A vector is an ordered collection of numerical components.

Example:

```python
vector = [2, 5, 3]
```

This vector contains three components and therefore has three dimensions.

Vectors can represent explicitly selected numerical features or numerical representations generated by machine learning models.

## 3. Mathematical Foundation

The magnitude of a vector is its length.

For a vector with \(n\) components:

\[
\|\mathbf{x}\| = \sqrt{\sum_{i=1}^{n} x_i^2}
\]

For the vector \([2, 5, 3]\):

\[
\|\mathbf{x}\| = \sqrt{2^2 + 5^2 + 3^2}
= \sqrt{38}
\approx 6.164
\]

## 4. Implementation

The program implements vector magnitude using Python's `math.sqrt()` and `sum()`.

It also reports the number of components using `len()`.

## 7. Observations

- Vector dimensionality is the number of components.
- Magnitude is calculated by squaring the components, summing them, and taking the square root.
- The zero vector has zero magnitude.
- Changing every component's sign does not change its magnitude.

## 8. Limitations

This implementation calculates magnitude only. It does not calculate similarity between vectors or generate embeddings.

## 9. Connection to AI Engineering

Vector magnitude is a mathematical building block for understanding vector normalization and cosine similarity.

These concepts will be useful when implementing embedding comparisons and semantic search for Enginuity-AI.

## 10. Key Learning

A vector provides a numerical representation of information, while its magnitude measures the length of that representation.
